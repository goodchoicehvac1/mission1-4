기능을 더하고,
확인·복구를 반복하기

실시간 영화 검색 기능을 추가하며 발생한 기존 기능 훼손을 발견하고 원본 기준으로 완벽 복구한 실전 경험

  • 발표자: 김선태 (굳초이스냉동공조)
  • 새로 더한 기능: 실시간 영화 제목 검색(필터링) 및 검색어 초기화 기능
  • 핵심 원칙: 새 기능이 동작해도 원래 되던 기능이 깨졌다면 원본 파일로 돌아가 복구한다!
01. 더할 기능 선정과 기획서 확장

왜 실시간 검색 기능인가? & 새 완성 기준

  • 기능 선정 이유: 등록된 영화가 많아졌을 때 특정 영화가 어느 등급에 있는지 한눈에 찾기 위해
  • 기획서 덧붙임:
  • 1) 검색창에 글자를 치면 해당 영화만 보이고 나머지는 숨겨진다.
  • 2) 검색어를 지우면 모든 영화가 원래 등급 자리에 다시 보인다.
  • 3) [원래 기능 보존]: 검색 중에도 드래그가 되고, 새로고침해도 등급 저장 상태가 유지되어야 한다.
💡 원칙: 기능을 더하기 전에 "무엇을 했을 때 어떻게 되면 성공인지" 완성 기준을 먼저 글로 써야 합니다.
02. 1차 결과물과 치명적 버그 발견

영화_기능추가.html: 새 기능은 되는데 원래 기능이 깨졌다!

  • 새 기능 확인: 검색창에 "기"를 치니 '기생충'만 잘 남음 (새 기능 통과)
  • 원래 기능 재검증 중 충격적 발견: 영화를 S칸으로 옮기고 F5(새로고침)를 눌렀더니 S칸의 영화가 미분류로 리셋됨!
  • 원인 분석: AI가 검색 필터 로직을 짜면서 init()에서 localStorage.getItem 불러오는 핵심 코드를 통째로 빠뜨림!
⚠️ 경계할 점 (회귀 버그):

AI는 새 기능을 짜느라 기존 기능의 소중한 로직을 사소하다고 여겨 날려버리기 쉽습니다!

03. 복구와 최종 완성 (영화_기능추가_수정1.html)

망가진 코드를 계속 땜질하지 않고 원본으로 돌아가기

  • 복구 전략: 망가진 영화_기능추가.html을 붙들고 씨름하지 않고, 잘 동작하던 영화_원본.html을 가져와 재요청
  • AI 요청문: "영화_원본.html의 localStorage 저장/불러오기 구조를 온전히 유지한 채 검색 기능만 결합해 줘."
  • 최종 검증:
  • - 실시간 검색 필터링 및 강조 완벽 동작
  • - 검색 상태에서도 자유로운 카드 이동 및 등급 저장 유지
  • - 브라우저를 닫았다가 다시 열어도 데이터 100% 보존 확인!
04. 미션 4를 통해 얻은 교훈

안전하게 기능을 확장하는 개발자의 기본기

  • 기존 기능 테스트가 먼저다: 새 기능이 아무리 멋져도 기존 핵심 기능이 깨졌다면 실패작이다.
  • 원본 보관의 위력: 잘 동작하는 원본(버전)을 백업해 두어야 언제든 안전하게 복구할 수 있다.
  • 현업 적용: 앞으로 굳초이스냉동공조 견적서 및 고객 관리 시스템에 기능을 하나씩 덧붙일 때도 반드시 '원본 보관 -> 기능 추가 -> 기존 기능 재검증' 3단계를 철저히 지키겠다.
